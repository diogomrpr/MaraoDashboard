Up to three independently configured readings. Each rounded tile shows its centered wrapping name, circular icon, then emphasized value/unit. Compact scalable spacing keeps the group transparent and aligns icons and values across long names. `variables.show_reading_names` defaults to true; false removes the visible name row while retaining semantic names and the separate group title. Hiding icons also removes their row.

## Try it

Try the card below. Select **Open playground** to choose a behavior or edit settings and YAML. Everything in the preview uses fictional devices. **Copy YAML** exports the card configuration, without demonstration states or service responses.

## Use in Home Assistant

In Home Assistant, choose **Edit dashboard → Add card → Manual**, then paste the YAML below. Replace fictional entity IDs with your own. You can also find the card in Home Assistant’s card picker and use its native editor.

```yaml
type: custom:marao-glance-card
name: At a glance
variables:
  entity1: sensor.temperature
  entity1_name: Temperature
  entity1_icon: mdi:thermometer
  entity2: sensor.humidity
  entity2_name: Humidity
  entity2_icon: mdi:water-percent
  entity3: sensor.house_power
  entity3_name: Power
  entity3_icon: mdi:flash
```

Each reading has its own rounded tile, with a circular icon above the value and wrapping name. Three tiles fit across a normal full-width phone layout with 8px gaps; fewer readings fill the available width. Narrower hosts or enlarged text reflow to fewer columns. Healthy tiles stay readable during partial availability.

Tap an Activity icon to inspect recorded events with date and type filters. Optional variables.activity_entities adds explicitly related sources. Automatic Updated and last-activation timestamps move into Activity; timestamp-sensor readings remain data.

Turn off **Show reading labels** in the card editor to show only icons and values. In YAML, set `variables.show_reading_names: false`. Labels remain visible by default; the group title has its own visibility setting. Custom reading names are retained when hidden and return when labels are enabled again. Activity buttons keep their entity names for accessibility.

Each of the three optional readings has an independent entity, name and icon. One unavailable reading does not erase the other values.

## Settings

The table lists the shared catalog fields and this card’s structured options. **Not set** means the example does not impose a value; Home Assistant and Marao use the entity’s capabilities and the card’s normal behavior. Structured values remain editable as YAML.

| YAML path | Setting | Value type | Catalog default | Behavior |
| --- | --- | --- | --- | --- |
| `name` | Name | text | Not set | Optional display name; otherwise use the entity’s friendly name. |
| `icon` | Icon | icon | Not set | Optional icon name such as mdi:lightbulb-outline. Searchable suggestions are available. |
| `variables.show_reading_names` | Show reading labels | boolean | `true` | Show or hide all reading labels without changing the group title or saved names. |
| `variables.entity1` | Reading 1 | entity | Not set | Reading 1 for this card. Searchable suggestions are available. |
| `variables.entity1_name` | Reading 1 name | text | Not set | Reading 1 name for this card. |
| `variables.entity1_icon` | Reading 1 icon | icon | Not set | Reading 1 icon for this card. Searchable suggestions are available. |
| `variables.entity2` | Reading 2 | entity | Not set | Reading 2 for this card. Searchable suggestions are available. |
| `variables.entity2_name` | Reading 2 name | text | Not set | Reading 2 name for this card. |
| `variables.entity2_icon` | Reading 2 icon | icon | Not set | Reading 2 icon for this card. Searchable suggestions are available. |
| `variables.entity3` | Reading 3 | entity | Not set | Reading 3 for this card. Searchable suggestions are available. |
| `variables.entity3_name` | Reading 3 name | text | Not set | Reading 3 name for this card. |
| `variables.entity3_icon` | Reading 3 icon | icon | Not set | Reading 3 icon for this card. Searchable suggestions are available. |
| `variables.activity_entities` | Related activity entities | json | Not set | Related activity entities for this card. Searchable suggestions are available. |
