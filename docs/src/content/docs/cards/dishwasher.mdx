## Use in Home Assistant

In Home Assistant, choose **Edit dashboard → Add card → Manual**, then paste the YAML below. Replace fictional entity IDs with your own. You can also find the card in Home Assistant’s card picker and use its native editor.

```yaml
type: custom:marao-dishwasher-card
entity_id: sensor.dishwasher
variables:
  progress_entity: sensor.dishwasher_progress
  remaining_time_entity: sensor.dishwasher_remaining
  active_program_entity: sensor.dishwasher_program
  salt_entity: binary_sensor.dishwasher_salt
  rinse_aid_entity: binary_sensor.dishwasher_rinse
```

Compatible entity domains: `sensor`, `input_select`.

Progress, remaining time and the actually active program are optional cycle readings, shown only while running, paused or awaiting a delayed start.

Missing cycle readings stay neutral and do not flag the appliance. Ready/inactive states stay compact; automatic height follows cycle content. Salt/rinse alerts and real machine faults remain visible.

## Behavior examples

Select **Open playground**, then choose a scenario to inspect its configuration and reported device state. Similar numeric or color values do not need separate examples.

| Scenario | What it demonstrates |
| --- | --- |
| Default | Try the configured card with fictional devices. |
| Icons and values | Hide indicator captions while keeping their accessible names. |
| Ready, no cycle data | Normal missing cycle readings do not create an appliance warning. |
| Idle | Inactive hides stale cycle values and retains the actual operation state. |
| Cycle with missing readings | A missing optional reading leaves the operation and other readings visible. |
| Finished | The completed cycle follows the reported state. |
| Salt warning | Only the configured abnormal consumable is prioritized. |
| Rinse-aid warning | A separate warning can be shown. |
| Appliance error | A reported error is explicit. |
| Loading state | Wait for Home Assistant state before showing controls. |
| Unknown state | The entity exists but has no known state. Controls remain neutral and disabled. |
| Unavailable | The entity is unavailable. No device action is dispatched. |
| Missing entity | A removed entity produces an explicit neutral missing-state result. |
| Disconnected | Controls refuse actions when Home Assistant is disconnected. |
