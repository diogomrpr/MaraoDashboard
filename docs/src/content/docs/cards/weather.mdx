## Use in Home Assistant

In Home Assistant, choose **Edit dashboard → Add card → Manual**, then paste the YAML below. Replace fictional entity IDs with your own. You can also find the card in Home Assistant’s card picker and use its native editor.

```yaml
type: custom:marao-weather-card
entity_id: weather.home
```

Compatible entity domains: `weather`, `sensor`.

The static sky reflects the reported weather condition; no background is animated. A large whole-number temperature appears with available wind, humidity and pressure readings. Metrics wrap naturally without empty slots; displayed current and forecast values are rounded without changing reported data. Tap the card to open hourly predictions or up to seven days on matching condition scenery, according to the entity’s capabilities. Explicit custom tap and hold actions retain their configured behavior. Missing forecasts stay empty and reported errors remain visible. `variables.show_forecast: false` hides the forecast entry.

## Weather station sensors

In the card settings, choose each station reading from its own searchable sensor dropdown: temperature, humidity, dew point, pressure, rainfall, wind speed, wind gust, wind direction, illuminance and UV index. Leave unused selectors empty. Existing station sensor mappings load automatically; editing one selector preserves the others. No YAML is needed for sensor selection. The optional wind angle label stays hidden by default while the compass arrow follows the direction sensor.

## Behavior examples

Select **Open playground**, then choose a scenario to inspect its configuration and reported device state. Similar numeric or color values do not need separate examples.

| Scenario | What it demonstrates |
| --- | --- |
| Default | Try the configured card with fictional devices. |
| Forecast | Show the native forecast below current conditions. |
| Current conditions only | Hide the forecast without changing the weather entity. |
| Rainy conditions | Weather icons and condition text follow the entity. |
| Weather station: raining | Pair sensor readings into compact instruments; 0.1 mm or more shows the rainy scene. |
| Weather station: not raining | A trace reading below 0.1 mm shows the clear scene. |
| Weather station: wind angle hidden | Hide the wind direction text while the compass needle follows the direction sensor. |
| Loading state | Wait for Home Assistant state before showing controls. |
| Unknown state | The entity exists but has no known state. Controls remain neutral and disabled. |
| Unavailable | The entity is unavailable. No device action is dispatched. |
| Missing entity | A removed entity produces an explicit neutral missing-state result. |
| Disconnected | Controls refuse actions when Home Assistant is disconnected. |

## Layout and shared behavior

Home Assistant owns card sizing, sections and visibility. Marao controls retain their touch targets and capability checks. Unknown, unavailable or disconnected entities use neutral presentation and disable unsafe actions. See [layouts and popups](../../features/layout/) and [shared interactions](../../features/theme/).
