## Which configuration should I copy?

Use the public `custom:marao-…` type shown on each page. The preview keeps fictional entity state separate from the exported configuration. Replace example entity IDs with your own before pasting into Home Assistant. Dashboard-wide navigation belongs in `marao.navbar`; its reference explains that placement.

## Compatibility names

The internal compatibility templates `md_access_slide_action_card`, `md_access_hold_action_card`, `md_header_card`, `md_access_action_card` remain available to existing configurations; they are not cards to choose for a new dashboard. Existing legacy `custom:marao-card` configurations with `md_*` templates and the `custom:marao-frigate-events-card` event alias remain compatibility forms. New examples use current public native types.

## Preview boundaries

These examples never connect to a Home Assistant account. Native dashboard editing, arbitrary third-party cards and real camera playback belong to Home Assistant; relevant pages state those limits.
