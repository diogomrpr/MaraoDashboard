## Use in Home Assistant

In Home Assistant, choose **Edit dashboard → Add card → Manual**, then paste the YAML below. Replace fictional entity IDs with your own. You can also find the card in Home Assistant’s card picker and use its native editor.

```yaml
type: custom:marao-graph-card
entity_id: sensor.house_power
variables:
  show_graph_line: true
  show_graph_fill: true
  history_popup: true
```

Compatible entity domains: `sensor`, `number`, `input_number`.

Tap the chart indicator or use the supported history hold to inspect recorded values. Opening history does not control a device.

power_devices adds selected device traces to the house power detail. Recorded data remains in its original units; formatting changes display only.

## Settings

The table lists the shared catalog fields and this card’s structured options. **Not set** means the example does not impose a value; Home Assistant and Marao use the entity’s capabilities and the card’s normal behavior. Structured values remain editable as YAML.

| YAML path | Setting | Value type | Catalog default | Behavior |
| --- | --- | --- | --- | --- |
| `entity_id` | Entity | entity | Not set | A sensor, number, input_number entity from your Home Assistant. Searchable suggestions are available. |
| `name` | Name | text | Not set | Optional display name; otherwise use the entity’s friendly name. |
| `icon` | Icon | icon | Not set | Optional icon name such as mdi:lightbulb-outline. Searchable suggestions are available. |
| `variables.show_graph_line` | Graph line | boolean | `true` | Graph line for this card. |
| `variables.show_graph_fill` | Graph fill | boolean | `true` | Graph fill for this card. |
| `variables.show_icon` | Show icon | boolean | `false` | Show icon for this card. |
| `variables.graph_color` | Graph color | color | Not set | Optional graph line/fill color. |
| `variables.graph_background` | Graph background | color | Not set | Graph background for this card. |
| `variables.history_popup` | History popup | boolean | `false` | History popup for this card. |
| `variables.power_devices` | Power devices | power_devices | Not set | Power devices for this card. |
| `variables.popup_hash` | Popup hash | text | Not set | Optional link to an existing external popup hash. Omit it to use this card’s automatic details. |
| `variables.display_unit` | Display unit | energy_unit | `Auto` | Auto keeps the source unit. Selecting a compatible unit converts the reading. Choices: `mW`, `W`, `kW`, `MW`, `GW`. |
| `variables.display_precision` | Decimal places | energy_precision | `Auto` | Auto trims trailing zeros. Choose 0–6 fixed decimal places. Choices: `0`, `1`, `2`, `3`, `4`, `5`, `6`. |
| `popup_view` | Custom popup view | text | Not set | Optional existing view path used for a Home Assistant managed popup layout. Omit for automatic details. Searchable suggestions are available. |

## Behavior examples

Select **Open playground**, then choose a scenario to inspect its configuration and reported device state. Similar numeric or color values do not need separate examples.

| Scenario | What it demonstrates |
| --- | --- |
| Default | Try the configured card with fictional devices. |
| Line only | Hide the area fill. |
| Fill only | Hide the graph line. |
| Power device breakdown | Inspect selected power sources alongside the house trace. |
| Compact graph | Disable the detail popup. |
| Empty history | No historical records are shown as an empty result. |
| History failed | A failed query has readable feedback. |
| Loading state | Wait for Home Assistant state before showing controls. |
| Unknown state | The entity exists but has no known state. Controls remain neutral and disabled. |
| Unavailable | The entity is unavailable. No device action is dispatched. |
| Missing entity | A removed entity produces an explicit neutral missing-state result. |
| Disconnected | Controls refuse actions when Home Assistant is disconnected. |

## Layout and shared behavior

Home Assistant owns card sizing, sections and visibility. Marao controls retain their touch targets and capability checks. Unknown, unavailable or disconnected entities use neutral presentation and disable unsafe actions. See [layouts and popups](../../features/layout/) and [shared interactions](../../features/theme/).
