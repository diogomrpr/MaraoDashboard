# Title Card

`md_title_card` displays a scalable section heading without a card background.
Generated pages use it to separate groups of controls. Its title wraps when
needed at narrow widths or enlarged text sizes.

```yaml
- type: custom:marao-card
  template: md_title_card
  name: Living Room
```

Use a [navigation card](md_navigation_card.md) with an explicit navigation path
for a page shortcut. Put scene controls in a [scene card](md_scene_card.md).
