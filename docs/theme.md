# Marao theme

The integration dynamically registers **Marao Dashboard** as a Home Assistant
theme. It uses an Atlantic blue and warm coral palette, responsive spacing,
rounded cards, and coordinated light and dark modes.

The builder assigns this theme to generated dashboards automatically. To use it
elsewhere, select **Marao Dashboard** in a dashboard or user theme setting.

The theme is available while the integration is loaded. Unloading the
integration removes it and restores any theme that previously used the same
name. Marao Dashboard does not copy files into Home Assistant's `themes`
directory and does not add anything to `configuration.yaml`.
