# Build a dashboard around your home

Marao Dashboard combines a visual dashboard builder, a responsive light and
dark theme, and a small set of custom Home Assistant cards.

The builder reads Home Assistant's area, device, and entity registries. It
creates an overview and one Sections view per selected area, grouping entities
into useful controls without changing `configuration.yaml`.
