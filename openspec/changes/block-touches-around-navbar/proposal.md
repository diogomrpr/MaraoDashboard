# Block touches around the navbar

Prevent accidental interaction with page cards beside and below the floating
navbar. Add a transparent full-width barrier from its top edge to the viewport
bottom, retaining navigation, overflow dismissal, popup interaction and previews.

Starting commit: `7b500719b6318261bd33a2bda13ce6a5e09c6341`.
Shared consumers: generated and native navigation surfaces in `MaraoNavigation.js`.
No configuration, saved-data, generator or editor contract changes.
