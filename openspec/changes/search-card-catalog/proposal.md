## Why
The Add card catalog requires scrolling through every card type. Administrators need to find cards directly.
## What Changes
Add a localized search field above Marao card types, filtering visible names/descriptions without losing the chosen card identity. Show an empty result message and restore the catalog when cleared.
## Capabilities
### Modified Capabilities
- `visual-builder`: searchable Marao card catalog.
## Impact
Shared visual builder, translations, styles and one focused regression. No persisted changes, migration, new dependencies or changes to entity/HA search.
